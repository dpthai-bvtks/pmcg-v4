📁 1. Chọn Thư Mục Lưu Tự Động Trên Máy Tính

Chọn thư mục trên máy tính (VD: D:\SaoLuu_PMCG). Mỗi khi sao lưu, trình duyệt sẽ tự động lưu file thẳng vào thư mục này mà không cần hỏi cửa sổ "Save As".

📁 Chưa chọn thư mục

☁️ 2. Cấu Hình Tự Động Upload Lên Google Drive

Nhập Webhook URL Google Apps Script của thư mục Google Drive. Cloudflare Worker sẽ tự động đẩy file sao lưu D1 lên Google Drive của bác sĩ hàng ngày (17:00).

📋 Xem hướng dẫn 3 bước tạo Webhook Google Drive (Miễn phí 100%)
  1. Mở Google Drive -> Tạo Thư mục mới tên "SaoLuu_PMCG" -> Mở thư mục -> Copy chuỗi ID trên thanh địa chỉ URL (Ví dụ ID: 1a2b3c4d5e...).
  2. Truy cập script.google.com -> New project -> Dán đoạn mã dưới đây: 
    function doPost(e) {
  var data = JSON.parse(e.postData.contents);
  var folder = DriveApp.getFolderById("DÁN_ID_THƯ_MỤC_VÀO_ĐÂY");
  var file = folder.createFile(data.filename, data.content, MimeType.PLAIN_TEXT);
  return ContentService.createTextOutput(JSON.stringify({status:"success", id: file.getId()}));
}
  3. Bấm **Deploy -> New deployment -> Select type: Web app -> Execute as: Me -> Who has access: Anyone** -> Copy URL Web app dán vào ô bên trên.
